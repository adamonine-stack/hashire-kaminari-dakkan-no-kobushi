# 主人公・敵の方向入力と基本技モーション

2026-10-10。主人公3人、敵9人の計12キャラクターに実装。前後の入力はキャラクターの向きを基準に判定します。

|操作|動作|特徴|
|---|---|---|
|P|素早い前方ジャブ|低威力・短い隙。既存の通常コンボへ連係|
|→ P|ステップパンチ|前方へ踏み込むスピードパンチ|
|↓ P|しゃがみ水平パンチ|姿勢と食らい判定を低くする|
|← P|上方向のかち上げ|ジャンプを迎撃し、ヒット時に浮かせる|
|↑ P|ジャンプパンチ|地上では跳びながら打つ。空中では空中パンチ|
|K|前方キック|パンチより高威力・長い硬直|
|→ K|出だしの早い単発キック|通常Kより発生が早い|
|↓ K|下段足払い|低い姿勢から脚を払う。ヒット時に転倒|
|← K|間合いを離す前蹴り|小さく水平に押す。浮かせ・転倒なし|
|↑ K|ジャンプキック|跳びながら蹴る。Pより着地後の隙が長い|

↑だけの通常ジャンプ、投げ、固有必殺技と反応モーションを維持。上下同時押しは中立として扱います。

## キャラクターの特徴

|キャラクター|構え・モーション|
|---|---|
|アッキー|コンパクトな総合格闘の構え。短い予備動作から鋭く踏み込む|
|豪|低い重心、太い腕の振り、大きく伸びる蹴り。重い回収|
|セイヤ|細身の身体を伸ばす軽い打撃。速い発生と回収|
|クラッシャー|巨体と厚い肩で押し込む重量級。大きな拳と蹴り|
|シャドウボクサー|高いボクシングガード。長い踏み込みと素早い拳の回収|
|高橋雅人|腰を落とす柔道家の構え。小さく踏ん張り、軸を保つ前蹴り|
|影山レイ|胸を開き、全身でかち上げる荒々しい打撃|
|クロス村雨|開いた手で間合いを制し、上体を反らせて押し蹴り|
|リオ・“フリック”・ガルシア|弾む体重移動。脚の溜めから鋭く伸びる蹴り|
|テキ|長い手足、深い腰構え、長いリーチ|
|レオン・クロウ|しなやかな上体、長く伸びる脚、滑らかな回収|
|闇セイヤ|セイヤの体格を維持して発生を調整。闇のオーラも維持|

発生・硬直はキャラクターごとに調整。前ステップ距離は30〜52。基本威力倍率はPが0.75〜0.90、Kが1.00〜1.15で、実ダメージに各キャラクターの攻撃力が反映されます。押し蹴りの基本押し戻しは横90、通常Kは横135。拳・脚の位置に当たり判定を合わせ、接触姿勢を戦闘のACTIVEフェーズと同期しています。

## 素材と実装

- `godot/data/basic_moves/`：12人×10操作の技リソース。
- `FighterDefinition.basic_move_paths`：操作と技IDの対応。
- `original_motion_sequences`：予備動作、打ち出し、接触、回収の専用クリップ。
- `godot/assets/characters/basic_moves_v2/`：ImageGenで敵8人の方向技128姿勢と、シャドウ・雅人の通常K／空中Pの16姿勢を新規作成。計144姿勢を組み込み。
- 主人公の既存専用素材と、敵の正常な通常・下段・空中素材も使用。闇セイヤはセイヤの専用身体モーションを追加読込。
- 透明背景。体格をフレームごとに拡大縮小せず、各キャラクター一定倍率でパック。支持足を基準に配置し、長い手足に必要なセル幅を確保。
- 生成ツール：`image_gen.imagegen`。保存プロンプト：[方向技](../godot/assets/characters/basic_moves_v2/generation_prompts.json)、[補足技](../godot/assets/characters/basic_moves_v2/supplement_prompts.json)。最初のシャドウ方向技の仕様は別途保存。

敵AIは近距離ジャブ・低突き、中距離キック、踏み込み、足払い、間合いを取る前蹴り、観察後の対空かち上げを使い分け、空中でも基本技の専用モーションを使用します。

↓Pの旧ランチャーは今回の水平パンチへ変更しました。旧技IDと、その技からのヒット確認ジャンプ→空中P→空中Kは互換用に維持。回帰テストでは旧ランチャーをIDで開始し、その後の実際のモバイル入力と衝突を確認しています。

## 確認結果

- `BASIC_MOVES_COMBAT_CHECK cases=240 failures=[]`：12人×10操作×左右。入力、接触フレーム、衝突ダメージ、一定の表示倍率、前ステップ、低姿勢、ジャンプ開始・着地、硬直中の判定停止、押し蹴りで相手に加わる水平速度を確認。
- 同チェックで通常コンボの入力連係、敵AIの状況選択・空中専用技も確認。
- コマンドバッファ、コマンド統合、旧空中コンボ、必殺技の切り返し、ステージ1回帰チェックは失敗なし。
- `BASIC_MOVES_RENDERED_OK clips=120`：Godotの実描画で全120クリップの各姿勢を出力し、接触姿勢の一覧を目視確認。
- [モーション確認ページ](../audit_evidence/basic_moves_20261010/rendered/index.html)：全キャラクターのGIFと技名。固定位置で姿勢を比較するページです。ジャンプ軌道とステップ移動は物理テストで確認。
- 作業前の復元ZIPとSHA-256は `audit_evidence/basic_moves_20261010/` に保存。

確認はローカルの自動操作と実描画です。実機の手操作、スマートフォン全編、Web公開は今回の確認範囲に含みません。既存回帰テストの一部は終了時にAudioStreamPlaybackの解放警告を出します。エディターの初期設定保存にも権限警告がありますが、新規画像のインポートとゲーム内読込は確認済みです。

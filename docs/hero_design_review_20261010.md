# ゴウ・セイヤの正式Idleとの整合性確認

## 完了状況

全体は未完了。キャラクターの正式デザイン確定、身体寸法±2%、全遷移の連続目視を合格と宣言しない。

PR #183 は main 90daf2228628fbe43bdc54a15b2de67e759571fe にマージ済み。Actions 38005686052 の build/deploy は success。公開Webの第一ステージ操作検証でアッキーの `Measured pose does not fit display cell` を検出したため、公開版の実行時検証は不合格。CI成功と公開実行時合格を区別する。

公開版の不具合はPCK書き出し後に `PackedFloat32Array` の素材倍率が空になることを、同じPCKのWindows実行でも再現した。`Array[float]` で値を保持する修正後、PCKの2,802フレーム検証（変更26）が合格し、ローカルWebの第一ステージで歩行・ジャンプ・攻撃・MAX必殺技の操作が実行時エラーなしで合格した。公開修正版の配信は未完了。CIには元プロジェクトだけでなく書き出したPCKの倍率と全フレームを検査する工程を追加した。

## ローカルの変更

- ゴウ・セイヤの全表示フレームを透明余白付き768×640キャンバスへ統一。元のatlas/regionを共有し、足元とピクセル原点、表示倍率を維持する。モーションごとの倍率調整は追加していない。
- 両者の打ち上げ攻撃は、既存の正式な対空アッパー素材へ差し替え。接触フレーム2、ダメージ、打ち上げ速度、アクション速度を維持。
- セイヤの頭部shaderで、透明余白を元画像のUV寸法と混同しないよう修正。
- ゴウの空中表示を実速度に応じてjump_start→jump_air→jump_fallへ遷移。ジャンプ速度や重力は変更していない。

## 身体・デザインの目視所見

正式Idleは変更しない。服装、髪型、顔、肩、腰、手足のつながりを、固定倍率の比較画像で確認した。ゴウのガード・投げ・キック・必殺技には屈伸や前傾があり、全身外接矩形の高さの変化だけを巨大化として扱わない。腕を伸ばす姿勢にも表示領域の端での切断は見つからなかった。

セイヤのパンチ、キック、必殺技はIdleより頭部が大きく見えるため、デザイン審査を不合格として記録した。髪の見える幅の手読み値はIdle42px、punch_1/0 47px、kick_1/0 48px、special_attack/0 47px、guard/0 37px。これは髪・頭部回転の影響を含む可視表面の比較で、頭蓋の寸法ではない。端点各±2pxの誤差があるため、この数値を身体寸法±2%の証明に使わない。

表示scaleは全フレームで一定。セイヤの既存head_scaleは基本素材0.9、修正済み追加素材のoverrideは1.0。既存の頭部検出矩形は髪・肌色の連結領域を含み、Idleの矩形高さ73pxなどが実際の頭の高さとは一致しない。元素材の頭身差とshaderの補正範囲を分けて調べ、正式Idleに忠実な素材修正が必要なフレームを特定する。倍率だけで身体全体を縮小しない。

回転・被弾・転倒・投げられ中の隠れた関節、腕脚の実長は外接矩形では評価できない。肩幅、胴体長、上腕/前腕/大腿/下腿、腰位置は、比較可能な姿勢の対応点を確定するまで未確認。

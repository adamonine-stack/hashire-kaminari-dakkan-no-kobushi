# ゴウ最終被弾: 低い高さ・上体反り・回転と着地を同期

2026-10-02。膝を引き寄せず、上体を反らして膝を軽く曲げた姿勢のまま後方270度回転。頭をゴウ側にしてうつぶせに倒れる。最新指定により、回転後にゆっくり下降する独立フェーズは除去した。回転中に下降し、物理的な床接触のフレームで回転と倒れ姿勢を同時に確定する。

浮き上がりは約25px。速度上限(420,-120)、専用飛行重力300で短い横移動約320pxを維持する。通常ジャンプ・投げ・アッキーの重力は変更しない。回転中の後半で原画の胴体位置を倒れ原画へ合わせ、床接触で突然位置が飛ばないようにする。

サイズ縮小への最新指摘を受け、原画パッキングの1.12倍除算と0.94倍縮小を除去。各敵の通常原画を基準に被弾原画を配置する。倒れ原画は高さで拡大するのでなく、原画の不透明面積を基準に、手足の重なりを考慮した空中姿勢の85%の身体面積に校正する。画面上のスケール、カメラ倍率、描画のピボットは一切変えない。回転中は同じ原画を使うため、途中で別の小さい姿勢に切り替わらない。

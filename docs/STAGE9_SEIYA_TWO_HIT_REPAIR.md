# 第9ステージ・セイヤのモーションと2段必殺技

本番の第9ステージはTRUEルートの `enemy_09_seiya`。敵・主人公双方のセイヤへ、サマーソルト→サイドキックの同じ2段制御を登録した。最終戦の主人公名簿・エンディング分岐・保存ID・台詞は維持。

## 確定した仕様

ユーザーの追加回答は「サマーソルト1倍とサイドキック1倍　サイドキックだけだと1倍です」。各段の基礎値は `max(punch_damage,kick_damage)`。主人公は13+13=26、最終ボスは24+24=48。片方だけなら13/24。ほかのキャラクターの必殺技は既存1.5倍を維持。

両段は別々の命中・ガード判定。初段ガード・空振りでも2段目へ移り、2段目単独でも命中する。各段の同一人物への重複ダメージは防止する。ガード中はダメージ0。ゲージは1発動につき1回だけ消費。

## デザインと描画

金髪、白いシャツ、黒ベルト、ベージュパンツ、白い靴、身長175cmと正式Sprite倍率を保持。通常104ポーズを単一人物・384×288の固定セルへ再配置し、別密度だった勝利・開始・歩行の素材を195pxの立ち姿基準に揃えた。姿勢ごとのランタイム拡縮は行わない。

頭部の局所0.90倍率は維持。頭の周りで読むUVを自身のセルに制限し、隣の頭・脚を読まない。逆さでは首が上、横倒しでは首が横にあることを反映し、頭と胴が離れる隙間を修正。116ポーズ分の髪の位置を事前計測し、パンツを頭として選ばない。回転中心は身体中心を使い、非等方Sprite倍率を逆変換する。身体中心はキャッシュし、毎物理フレームの画像読出しを避ける。

新しい攻撃8ポーズと主人公3人×4受け手ポーズをbuiltin imagegenで制作。元の肌・服・人物を保持し、1頭・2腕・2脚、オーラや別人物を本体に焼き込まない。受け手はlift/fall/fly/downを独立登録。敵1〜8は既に修復済みの専用素材を同じ2段反応へ接続する。ボスの濃い必殺オーラを外周の弱い光へ変更し、顔や足と蹴りの接触が読めるようにした。

制作指示・参照・生成PNGは `art_sources/seiya_two_hit_v1`、完成素材は `player03/animations/seiya_v2` と `two_hit_v1`、受け手は各主人公の `seiya_two_received_v1`。再構築は `tools/build_seiya_two_hit.py` → `tools/finalize_seiya_two_assets.py`。

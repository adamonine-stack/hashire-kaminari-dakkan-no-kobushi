# Stage 3: テキ・ファイター

The third published opponent is now the existing `enemy_07_teki_fighter` identity,
after Crusher and Rei. Masato remains in the complete roster at position seven.
The first two stages, ally balance, saved fighter IDs, rotation, recovery, and
selection handlers are preserved. Defeating Teki shows `STAGE 3 CLEAR`.

## Authored motion

The built-in ImageGen tool produced two new transparent sheets using the supplied
design as an identity reference. No pixels from the reference page are used as
combat frames. The design retains long brown hair, a white short-sleeve shirt,
loose black trousers, open-hand grappling stance and burgundy high-top sneakers.

52 poses are packed into a 3072 × 2016 atlas with 384 × 288 cells and 72 animation
names. Connected-component isolation prevents neighboring limbs entering a cell;
the supplementary sheet uses a single 0.66 scale for consistent body height.
Both source sheets and the packing manifest are retained. Source art is excluded
from Godot imports by `.gdignore`.

Normal combat includes palm punch, elbow, high kick, sweep, aerial punch/kick,
guard, recoil, knockdown, get-up and non-looping KO. Throws cycle between rotating
throw, face grab, headlock and low grab. Deadly Hand
spends the normal special gauge, telegraphs before contact and enters the existing
face-grab/escape pipeline. Missing leaves a recovery window. Grabs use existing
single damage, escape and regrab-lock rules.

  three opponents, HUD identity, 52-frame references, both-facing contact timing,
  four grab animations with target lock and single damage, escape, Deadly Hand,
  Stage 3 clear and retry back to Crusher.
- `tests/teki_visual_review.gd`: rendered frames for all 72 clips, attack shape
  overlays on both facings, and paired grab screenshots. `-- --contacts-only`
  restricts a repeat review to contact and grab images.
- The deployment workflow runs the three-stage regression before Web export.
- Existing Stage 2 regression explicitly scopes itself to two stages.

Build the atlas with Node and Sharp using `tools/build_teki_motion_atlas.cjs`.
`tools/configure_teki_stage3.cjs` records the one-time resource migration and
refuses to overwrite an already configured installation.

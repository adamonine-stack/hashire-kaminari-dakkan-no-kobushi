# 1.2 ゲームコンセプト

「誰でも遊べるシンプル操作の格闘ゲーム」

本作品は、ストリートファイター初代のようなシンプルな操作性と、
家庭用ゲームらしい達成感を目指した2D格闘アクションゲームである。

プレイヤーが難しいコマンドを覚える必要はなく、
少ないボタンだけで爽快なバトルが楽しめる。

ゲームクリアまで約20分で遊べる内容とし、
何度でも繰り返し挑戦したくなるゲームデザインを採用する。

# 1.9 主人公3人とローテーション

ゲーム開始時から以下の3人を使用可能とする。

・アッキー

・ごう

・せいや

各ステージ開始前に、そのステージで戦う1人を選択する。

主人公3人の最大HPは従来バランス値の50%を基本値とし、HPゲージの表示幅は従来と同じとする。

ステージを勝利した場合、そのステージで戦わなかった生存キャラクター2人は、それぞれ自分の最大HPの20%を回復する。

実際に戦闘したキャラクターは勝利後も回復しない。

戦闘不能になったキャラクターは、そのラン中は再選択できない。

このローテーションと休養回復を利用し、3人の残HPを管理しながら9ステージを攻略する。

---

# 1.10 勝敗条件

各ステージは1ラウンド制。

相手のHPを0にすると勝利。

主人公のHPが0になるとそのキャラクターは戦闘不能となる。

同じ敵のHPは維持され、残っている主人公から次の1人を選択して戦闘を継続する。

主人公3人全員が敗北した時点でゲームオーバーとなる。

ゲームオーバー時は第1ステージから再開する。

制限時間は設けない。

引き分けは存在しない。

# セイヤのモーション修正・最終描画検証（2026-10-10）

## 修正内容

提示画像の不自然な開脚は `crouch_punch` の途中フレーム（元セル57）。既存の膝を折った正式素材セル56へ置き換え、6フレーム・12fps・攻撃接触フレームを維持した。打ち上げ攻撃は既存の上向き攻撃素材へ切り替え済み。描画キャンバス768×640と足元原点を共通化し、手足が広がる動作でも身体を縮小しない。

追加点検で、頭部補正が身体へ及ぶ原因を修正した。

- 頭部ランドマークは元セル内座標、身体中心は透明余白付き表示画像座標だった。身体中心と自動ランドマーク検出を元セル座標へ統一。倒れた姿勢・逆さの姿勢で補正方向がキャンバス余白に左右されない。
- 基本素材34セルの頭部補正矩形が拳・前腕・胸まで含んでいた。元画像の頭・首の範囲へ矩形を絞った。以前に修正した髪の分断等の5セルも維持。
- 白い襟・肩が矩形内の頭部縮小に巻き込まれ、透明な縦の切込みになっていた。連続する無彩色の服の画素を元座標で保持。孤立した目の白やハイライトを服と判定しないよう周辺画素も確認する。

正式な元画像24アトラスは変更していない（SHA-256台帳保存）。全身の表示倍率やモーション別倍率を追加していない。既存の基本素材の頭部補正0.9、正式追加素材の補正不要指定1.0を維持。HP・攻撃力・速度・攻撃判定・アニメーション速度は今回変更していない。

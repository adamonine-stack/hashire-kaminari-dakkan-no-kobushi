# 第7ステージ マサトの全身・二重人物・肌の欠け修正

旧ビルダーは1261×1247の不均等な36原画を6×6で等分し、顔や手にも適用する彩度除去で肌の画素を透明にしていた。投げ原画には別人物の頭が混ざるコマもあった。

元の全身領域を計測して復元し、彩度0.8を超える背景フリンジだけを抽出境界から除く。輪郭内は元RGBAを復元して肌色を維持。全復元原画に一つの倍率を使い、旧待機高295px、168cmの設定、512×448セル、404px接地基準を固定。

混合人物の旧投げ24〜29は使用対象から外し、新アトラスの該当セルにもマサト単体を配置。built-in image_genで正式参照から9原画を再制作した。しゃがみパンチ2、足払い1、空中蹴り1、掌底2、投げ3。生成素材・正式参照・全文プロンプトはart_sources/masato_motion_v2/。

立ちガードとしゃがみガードを分離し、通常キックの打撃を蹴り原画へ同期。投げの開始・保持・放しを汎用throwで上書きしない。掌底の再生進行を保ち、予備・打撃・戻りを表示する。変更対象IDはマサトのみ。HP、ダメージ、技の時間、ヒットボックス、AI、各ステージと他キャラクターの原画は維持。

三人の必殺技を受ける追加原画を同じセルと接地位置に再配置。各反応系列に同一倍率を適用し、頭からの着地・回転・壁反応を維持する。

検証はBattle.tscnの第7ステージで全152フレーム、左右78種類の表示と通常攻撃・ガード・投げ・掌底の実接触を確認する。頭・手・足がセル境界で切れないこと、固定スケール、接地位置、画面内全身、通常fallbackスプライトとの重複がないことを検査。主検証98枚、Akky/Gou/Seiyaの実飛行・転倒・ガード・KOは14/24/40枚。

人物の頭と脚の数は全使用主原画32種類と反応7種類を目視確認する。人物数の自動判定とは区別する。元投げコマ24〜29が使用されないことを確認。

公開検証用Nodeシーンは新規ブラウザーの一回フラグだけを使い、配信PCK/WASMを変更しない。PCとモバイル相当の制御戦闘は手動プレイや実機スマートフォン確認とは区別する。公開後の結果はevidence/MASATO_RELEASE_RESULT.mdに記録する。

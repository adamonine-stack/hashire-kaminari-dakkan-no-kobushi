# 第二ステージ デザイン・受けモーション公開

レイ・カゲヤマの正式Idleと同じマスター画像から必殺技・投げの受けを登録し、ジャンプ上昇/下降の切替と、投げ保持/放出/着地の表示を修正した。主人公の既存専用受け素材を再利用した。新規キャラクター画像は生成していない。

## 原因と変更
- 旧受け画像には正式マスターと異なる身体比率があり、セイヤ用受けがゴウ用の画像を参照していた。16クリップを正式マスターの被弾・空中・転倒姿勢に置き換えた。
- レイのジャンプにjump_ascentがなく、空中でjump_startが続いていた。既存の上昇姿勢を登録し、共通の速度による状態選択を有効にした。
- 共通768×640キャンバスを使用し、足元アンカーと通常倍率1.156091を維持。攻撃時のみの倍率補正は追加していない。
- 主人公からの方向別投げ受け6クリップが不足していた。既存マスターから登録した。
- レイの通常投げは保持と放出を区別して表示し、主人公の保持・空中・着地を既存専用素材へ接続した。
- HP、威力、速度、判定、投げ物理、タイマーは変更していない。

## 合格した検証
- Godot実描画: 修正前後2730方向別フレーム比較。固定倍率、左右反転、キャプチャ端の切れを検証。
- 最終レイの全352方向別フレーム: リソース契約、固定倍率、正式マスターへの受け参照を検証。
- 実Battle第二ステージで主人公3人×左右×4方向投げ、およびレイ→主人公3人×左右の30組を再生。固定倍率、保持/空中のクリップ、1回のダメージ、着地、起き上がり、拘束解除は全組合格。
- 主人公3人とレイの連続アクション: 各12ケース、実Godot描画で確認（自動操作）。
- 必殺技の受け、第二ステージ回帰、第一ステージの投げ回帰は合格。
- CIに設計契約・30投げ組・主人公必殺技3種のレイ受け検証を追加。

## 不合格・未確認
- 不合格: レイ→アッキー保持時の手と身体の接触位置にずれ。姿勢切替の合格とは別項目として継続課題にした。公開は全視覚問題の解決を意味しない。
- 未確認: 部位ごとの身体寸法±2%、人による手動プレイ、公開Web上で全30組の再現。
- テスト終了時に一部ObjectDBリーク警告が残る。SCRIPT ERRORと分けて記録。

# セイヤ正式サイズ・最終ボス実装記録

## 主人公の正式基準

アッキーに近い頭の大きさと細身の輪郭を目標に、元のセイヤの顔・髪・服・靴を保持した。キャラクター設定の身長175cmは維持。立ち姿の膝の曲がり方が違うため、頭頂を無理にアッキーと同じ高さにはしない。

接地原点はY=0。GroundContact、HurtBox、通常攻撃と主人公必殺技のHitBox、Shadowを合わせて調整。頭は髪のフレーム別ランドマークに従う局所Shader変形で、別の顔を描き直していない。主人公とボスで同じ定義値・同じ通常atlas・同じ足元を使用する。

[変更前](../evidence/seiya/size_before.png)、[正式比較画面](../evidence/seiya/size_comparison.png)はアッキー・ごう・主人公セイヤ・ボスセイヤを同じ地面に配置したGodot描画。セイヤだけ一回り大きく見える状態を解消し、肩・胴を細くした。ボスの見かけの広がりは別レイヤーのオーラ。

## 検証・問題と修正

- Godot 4.7実描画：同地面比較、主人公77クリップ、ボスIdle・Walk・Dash・Jump開始/空中/落下・Punch1/2・Kick・Guard・被弾・KO・溜め開始/最大・振り下ろし・接触・復帰の全フレームを描画確認。単にアニメーション名を確認した検証ではない。
- 専用実物理テスト：主人公/ボス同一倍率、HP/攻撃力、溜めと予兆中の無判定、単発26ダメージ、終了後無判定、狙い位置固定、横移動回避、実ジャンプ回避、被弾中断、遠距離AI、連発禁止、中距離キック、165px離れた実相手へのオーラパンチが成功。
- 既存 `seiya_motion_atlas`（85クリップ285フレーム）、`true_seiya_combat_check`、`stage1_regression`、`stage8_ending_check` は全て failures=[]。キャラクター選択・開始・移動・攻撃・被弾・敵撃破・クリア/リザルト・再挑戦・最終分岐を自動確認。
- 頭の検出がパンツ色を拾う初期不具合を、髪の連結領域を選ぶ処理と事前ランドマークに修正。姿勢ごとの全体倍率変更をせず頭だけ追従。
- ボスの攻撃値が既存敵用倍率で弱くなる問題を、定義の明示的なdirect stats設定で修正。他の敵の既存倍率は維持。
- 旧主人公描画検証が開始会話で待ち続ける問題を、会話送り後に検証する処理へ修正。
- 特別技テストの被弾入力にSE項目が欠ける初期テストエラーを修正し、エラーなしで再実行。
- 最初のオーラは輪が目立ち、屈み姿勢に対して高すぎた。紫黒の煙Textureへ整理し、頭から足元までの現在姿勢に追従させて再描画・Web検証。
- ローカルWebのデスクトップ1280×720、モバイル相当844×390で実AIの溜め・予兆・柱・単発ヒット、移動・ジャンプ・攻撃を確認。通常保存データを新しいブラウザーのみに準備し、ゲームPCK/JS/WASMは改変しない。
- ブラウザーのソフトウェアWebGLにbuffer警告が残る。追加エフェクトをTexture/矩形にしても再現し、JS例外・Godot SCRIPT ERROR/ERROR・通信失敗はなし。警告の根本原因解消は未確認。
- ネイティブ画面操作はウィンドウ取得タイムアウトで手動操作を完了できなかった。上記はGodot描画と自動実ゲーム検証であり、全項目の人間による手動プレイや実機スマートフォン確認を意味しない。

## 素材生成の再現情報

imagegenで制作した素材：`ground_contact_source.png` と `dark_seiya_pillar.png`。本体の大量一括生成は行っていない。

地面接触の制作指示：既存セイヤの参照を厳守し、同じ金髪・顔・白いボタンシャツ・ベージュパンツ・スニーカーのまま、横向きに腰を落として閉じた拳を地面へ叩きつける一枚。透明背景、全身、既存ドット絵の輪郭と頭身、オーラや文字を本体へ焼き込まない。

オーラ制作指示：透明背景の紫黒の闇の柱。炎ではなく黒い煙と紫の縁・粒子が地面から立ち昇る。ゲーム用エフェクトのみ、人物・文字・背景なし。実際の幅84/高さ96へ映す専用HitBoxと併用。

atlas再構築：bundled Nodeとsharpで `tools/build_dark_seiya_atlas.cjs` を実行。元atlasの必要フレームを再利用し、地面接触一枚を足元基準で配置。PNGとTRESとJSONを保存済みのため実行時の生成は不要。

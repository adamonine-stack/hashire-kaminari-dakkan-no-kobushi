# セイヤ 正式モーションデザイン (2026-10-07)

正式な体格は、修正済み立ち姿（ally_speed / idle_prebattle 0、seiya_v2 frame 94）の実描画を採用する。
参照画像: art_sources/seiya_slim_v3/formal_standing.png。
体格の釣り合いは akky_balance_reference.png、しゃがみキックは akky_sweep_reference.png を比較する。
頭だけ極端に縮小して相対的に身体を巨大に見せることは禁止。
しゃがみキックは太もも/すね/靴を伸ばさず、立ち姿の脚と同じ長さ。
従来の大きい丸顔・太い腕や脚を含む動作素材を、今後の制作基準にしない。

- 同じ金髪、顔、白シャツ、黒ベルト、ベージュパンツ、白スニーカー。
- 立ち姿の小さめの頭、細い肩/胴、細身の腕/脚を全ポーズで保持。
- 大きい衣服の膨らみや肩幅で、筋肉質・幼い体型に変えない。
- 顔の詳細を失わず、倒れ/横向き/逆さまでも同じ頭の大きさ。
- 関節を曲げることで動きを出し、脚や腕の長さ、身長を増減させない。
- 地上/空中/ダウンは同じ体長。物理位置と画像の足元/掴み位置を分離。
- 既存 body_width_scale/head_scale の補正があるため、素材側で修正した比率を二重に縮小しない。
- 新規動作は「正式立ち姿→キーポーズ比較→中間フレーム→全フレーム比較→Atlas→実描画」の順。
- 通常攻撃だけでなく、Guard・Throw・被弾・必殺技・他キャラからのSpecial受けも対象。

139枚の重複しない現行表示フレームを描画監査済み。分類と参照先は design_manifest.json。
旧素材を破棄せず、修正版は別バージョンで保存し、品質確認後にのみゲームへ接続する。

## 今回の接続範囲

しゃがみキックの準備・蹴り出し・接触・引き戻し・復帰を新規作成し、slim_sweep_v3 を接続。
全ポーズは同じ倍率でAtlas化し、素材側で調整済みの頭を再縮小しない。
HitBoxを60×28、中心を前方62pxへ変更。発生・硬直・威力・ダウン属性は維持。
実描画でアッキーとの体格を比較。自動実戦テストでは左右両向きの地上命中・ダウンと、空中相手への空振りを確認。
他の攻撃・ガード・投げ・被弾モーションの全面修正は継続対象であり、完了扱いにしない。

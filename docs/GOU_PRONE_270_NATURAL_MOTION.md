# ゴウの自然な後方270度・うつぶせ着地

2026-10-02。立位対面→頭から後ろへ回る→頭をゴウ側にしてうつぶせ、という到達姿勢は360度ではなく270度。前工程の360度+姿勢切替を補正した。

- 全9敵へ膝を引き寄せる中間原画9枚をbuilt-in image_genで追加。art_sources/gou_received_v2に既存の開始/着地18枚と合わせ計27枚。生成指示はprompt_manifest.json。
- 空中Clipは反らす→膝を引く→手足を開く3コマ。物理進捗に同期し、回転は60Hzで270度まで単調に進む。中間コマの切替はgou_pose_blend.gdshaderで短く補間し、瞬間的な姿勢切替を抑える。
- 中間原画は立位高さの75%へ体格を較正し、胴体中心の位置を揃える。着地原画は頭から足までの長さを立位に合わせ、低い姿勢を拡大しない。Sprite Scaleとpositionは固定。
- 270度で頭がゴウ側・胸が床側になってから、うつぶせ原画へ接続。原画の胴体中心を合わせ、最後の下降で床へ滑らかに移す。着地時に回転、描画offset、補間materialを復元。
- 飛距離約310〜320px、速度(420,-400)、ダメージ、ガード、KO、アッキーの壁衝突を保持。

確認: 全9敵×左右で中間/開き姿勢、単調270度、頭の方向、うつぶせ下降と着地の復元が成功。gou_270_motion_check.logはfailures=[]。gou_270_render.logは実Battle.tscn描画203枚、failures=[]。膝引き寄せ・開く姿勢と着地画像を確認。既存25/25回帰と共通必殺技/アッキーモーション/壁反応も成功。
